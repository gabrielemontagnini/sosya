# dmz-redis

Struts2 in a DMZ, passwordless Redis only on the internal network

Start with `sosya shell dmz-redis`: a Kali box inside the range.

## Objectives

1. Get a shell on web
2. Pivot from web to cache and read the flag

## Network map

| Network | Hosts |
| --- | --- |
| dmz | attacker, web |
| internal | web, cache |

The attacker box joins dmz and has internet access. Targets have no internet access. A host on two networks is the only way from one to the other.

## Hosts

| Host | Networks | Services | Flag |
| --- | --- | --- | --- |
| web | dmz, internal | web (8080/tcp) | `/root/flag.txt` |
| cache | internal | cache (6379/tcp) | `/tmp/flag.txt` |

Flags look like `SOSYA{...}` and change every time the range starts.
